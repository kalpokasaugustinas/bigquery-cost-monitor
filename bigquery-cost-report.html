BigQuery cost report

Who and what drives your BigQuery bill, and where to cut.

Costs are for on-demand pricing, where BigQuery bills the data each query reads ($6.25 per TiB). On capacity pricing (BigQuery editions) you pay for slot time instead: a fixed amount for committed slots, plus whatever autoscaling uses. There the dollar figures are not your bill. Use slot hours to compare.

        The report is empty or shows too few queries
        
BigQuery keeps job history per region and per project, and one run covers one region of one project.
          Find where your queries run: BigQuery console → Personal history (bottom panel) →
          open one of your queries and note its project and location.
          Put that location in the Region field in step 2 (for example EU or europe-west1)
          and that project in the Projects field, then copy the script again.
          Data in several regions? Run the script once per region and drop all files here. They are merged into one report.

      

      

        BigQuery says it could not compute bytes processed
        
That's expected. The script builds its queries while it runs, so BigQuery can't estimate the cost in advance.
          It still runs normally and costs a few cents on most projects.

      

      

        Can I check several projects at once?
        
Yes, if they are in the same region. List them in the Projects field in step 2,
          for example my-project, my-other-project, then copy the script. You need permission to see job history in each project.
          Including the projects that query each other's tables also makes the unused tables list more accurate.

      

      

        I only see my own queries        
Seeing everyone's queries needs the bigquery.jobs.listAll permission,
          for example through the BigQuery Resource Viewer role. Ask your admin, or run the script as someone who has it.

      

      

        How are costs calculated?
        
Query cost is data billed × $6.25 per TiB (on-demand list price). Storage cost is $0.02 per GiB per month
          for active and $0.01 for long-term storage (logical billing, US list prices).
          Free tier, discounts and regional prices are not included, so treat the numbers as estimates.
          If your queries run on capacity pricing (editions, reserved slots), the report says so and the dollar figures
          show what they would cost on-demand, not what you pay.

      

      

        Is my data safe?
        
Yes. This page runs entirely in your browser and works offline. The file you drop is never uploaded anywhere.
